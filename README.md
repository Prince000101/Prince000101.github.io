## ✦ Selected Works

### [Downtube GUI](https://github.com/Prince000101/Downtube__-ytdlp_gui-__application)
> A Python desktop application built for Linux utilizing `yt-dlp` to cleanly and efficiently download YouTube media. Focuses on performance and a clean user interface.

### [Face Recognition](https://github.com/Prince000101/face_recognition-open-cv-)
> An exploratory machine learning project implementing real-time facial recognition utilizing **Python** and **OpenCV** architectures.

> A robust backend system leveraging **Java**, **SpringBoot**, and **Hibernate ORM** for secure data journaling architectures.

### [Cashier System](https://github.com/Prince000101/Cashier-software)
> A complete supermarket point-of-sale software solution built entirely from scratch using **Java Swing**.
